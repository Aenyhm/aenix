# AeNix

NixOS configuration of my machines, a personal desktop and a work laptop, with a personal session and a work session. The whole system lives in this flake, so a machine can be rebuilt from scratch, and a broken update is undone by booting the previous generation.

| Document | Read it to |
|---|---|
| [docs/install.md](docs/install.md) | install a machine, from a blank disk to a configured desktop |
| [docs/how-to.md](docs/how-to.md) | update, find or change a setting, sync the work files, fix what fails, upgrade NixOS |

## How the repository is organised

Every file under `modules/` is loaded by import-tree, and a feature keeps its NixOS and home-manager halves in the same file. A host imports the features and the users it has, and each user lists the home-manager profiles they get.

| Path | Holds |
|---|---|
| `modules/hosts/<host>/default.nix` | a machine: the features and users it imports, its `stateVersion`, what only it has |
| `modules/hosts/<host>/hardware.nix` | disks, kernel modules and CPU, generated by `nixos-generate-config` |
| `modules/users/<user>.nix` | a person: name, email, taskbar launchers, profiles, and the applications only they use |
| `modules/system/` | base system shared by every host (users, locale, network, audio, Bluetooth, printing, nix-ld), boot, Nix, Docker, home-manager wiring |
| `modules/system/desktop.nix` | the KDE desktop, its settings and its login screen |
| `modules/system/gaming.nix` | Steam, gamemode, and the `gaming` profile |
| `modules/apps/` | the `apps` profile every user gets: one file per configured application, `common.nix` for the rest |
| `modules/services/` | Syncthing and the music share of the NAS |
| `modules/flake-parts.nix` | values shared by every module: the monospace font, the colour palette, the default browser, the private values |

Two things live outside this repository, to keep them off a public GitHub:

| Where | What |
|---|---|
| `Aenyhm/aenix-private`, a private flake input | the personal values and the work module, loaded by import-tree like `modules/` |
| the `work` Syncthing folder, at `~/sync/work` | the work files, linked from the home directory and the repositories |
