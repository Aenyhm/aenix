# AeNix

Nix configuration of my machines. The PCs run NixOS, with a personal session and a work session. The Mac keeps macOS: nix-darwin installs its apps through Homebrew and gives its main account the same config as on Linux. The whole system lives in this flake, so a machine can be rebuilt from scratch, and a broken update is undone by booting the previous generation.

| Document | Read it to |
|---|---|
| [docs/install.md](docs/install.md) | install a machine, from a blank disk to a configured desktop |

## How the repository is organised

Every file under `modules/` is loaded by import-tree, and a feature keeps its NixOS and home-manager halves in the same file. A host imports the features and the users it has, and each user lists the home-manager profiles they get.

| Path | Holds |
|---|---|
| `modules/hosts/<host>/default.nix` | a machine: the features and users it imports, its `stateVersion`, what only it has. `mac` holds the whole Mac |
| `modules/hosts/<host>/hardware.nix` | disks, kernel modules and CPU, generated by `nixos-generate-config` |
| `modules/users/<user>.nix` | a user: identity, profiles, and what only they use |
| `modules/system/` | the system shared by every NixOS host |
| `modules/system/kde.nix` | the KDE desktop, its settings and its login screen |
| `modules/system/gaming.nix` | the games and the `gaming` profile |
| `modules/apps/` | the `apps` profile every NixOS user gets: one file per configured application, `common.nix` for the rest. The ones the Mac shares are modules of their own too, which it imports alone |
| `modules/services/` | the background services |
| `modules/flake-parts.nix` | the values shared by every module |

Two things live outside this repository, to keep them off a public GitHub:

| Where | What |
|---|---|
| `Aenyhm/aenix-private`, a private flake input | the personal values and the work module, loaded by import-tree like `modules/` |
| the `work` Syncthing folder, at `~/sync/work` | the work files, linked from the home directory and the repositories |
